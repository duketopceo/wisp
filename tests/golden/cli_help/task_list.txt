usage: wispd task list [-h] [--grep TEXT] [--json] [--quiet] [--no-color]

List background agents; --grep finds a past run by its subject or what it learned

options:
  -h, --help       show this help message and exit
  --grep, -g TEXT  only runs whose task text, name or learned line contains
                   TEXT

global options:
  --json           machine-readable output (one JSON object)
  --quiet, -q      print nothing on success
  --no-color       plain output (also NO_COLOR, or not a tty)

Examples:
  wispd task list
  wispd task list --grep flaky
