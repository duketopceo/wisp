usage: wispd dictate correct [-h] [--json] [--quiet] [--no-color] heard meant

Teach dictation a replacement: heard -> meant

positional arguments:
  heard        what was transcribed
  meant        what should replace it

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd dictate correct "wisp dot ai" "wisp.ai"
