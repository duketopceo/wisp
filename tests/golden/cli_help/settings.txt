usage: wispd settings [-h] [--category NAME] [--json] [--quiet] [--no-color]

Open the settings window

options:
  -h, --help       show this help message and exit
  --category NAME  page to open (default home): home, activity, memory, tasks,
                   voice, pointer, agents, models, budget, connectors,
                   advanced, health, spend, audit, binds

global options:
  --json           machine-readable output (one JSON object)
  --quiet, -q      print nothing on success
  --no-color       plain output (also NO_COLOR, or not a tty)

Examples:
  wispd settings
  wispd settings --category budget
  wispd settings --category health
