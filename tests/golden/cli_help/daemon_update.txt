usage: wispd daemon update [-h] [--dry-run] [--force] [--sha256 HEX]
                           [--restart] [--rollback] [--json] [--quiet]
                           [--no-color]

Fetch the latest release, verify it, and install on your yes

options:
  -h, --help    show this help message and exit
  --dry-run     print version, digest and the files that would change; write
                nothing
  --force       install a release that is older than, the same as, or cannot
                be compared with what is installed
  --sha256 HEX  expected SHA-256 of the download, for a release that publishes
                none
  --restart     after a verified install, offer to restart wispd and check
                that it answers (with --rollback: after restoring)
  --rollback    restore the files saved before the last update (also the way
                back from an unfinished update)

global options:
  --json        machine-readable output (one JSON object)
  --quiet, -q   print nothing on success
  --no-color    plain output (also NO_COLOR, or not a tty)

Examples:
  wispd update --dry-run
  wispd update
  wispd update --restart
  wispd update --rollback
  wispd update --force
