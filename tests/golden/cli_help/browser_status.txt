usage: wispd browser status [-h] [--json] [--quiet] [--no-color]

Show the native host files, and whether wispd serves the lane

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd browser status
  wispd browser status --json
