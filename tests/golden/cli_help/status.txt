usage: wispd status [-h] [--table] [--json] [--quiet] [--no-color]

Show the daemon state (JSON)

options:
  -h, --help   show this help message and exit
  --table      print every status word and tone (no daemon needed); see
               docs/EMBED.md

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd status
  wispd status --json
  wispd status --table --json
