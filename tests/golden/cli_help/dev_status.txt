usage: wispd dev status [-h] [--json] [--quiet] [--no-color]

Show whether dev mode is on and how many runs are left

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd dev status
  wispd dev status --json
