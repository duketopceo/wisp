usage: wispd ask [-h] [--stdin] [--json] [--quiet] [--no-color] [text]

Ask one typed question (starts a normal turn)

positional arguments:
  text         the question to ask, as one argument

options:
  -h, --help   show this help message and exit
  --stdin      read the question from one line of stdin

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd ask "what is the front wheel for?"
