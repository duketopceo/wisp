usage: wispd latency [-h] [--since AGE] [--budgets] [--baseline] [--harness]
                     [--json] [--quiet] [--no-color]

p50 and p90 per budget path from recent turns

options:
  -h, --help   show this help message and exit
  --since AGE  window: 24h, 90m, 2d (default 24h)
  --budgets    print the budget table instead of a report
  --baseline   show the committed harness baseline (fakes)
  --harness    measure now from the replay harness (fakes, needs a repo
               checkout)

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd latency
  wispd latency --since 6h --json
  wispd latency --budgets
  wispd latency --harness
