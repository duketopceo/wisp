usage: wispd daemon install [-h] [--cua] [--units] [--echo-cancel] [--dry-run]
                            [--from-plugin] [--yes] [--ref GIT_REF]
                            [--repo PATH] [--json] [--quiet] [--no-color]

Install runtime files, the systemd unit and the hotkey bind

options:
  -h, --help     show this help message and exit
  --cua          also install the pinned cua-driver (scripts/cua/install.sh)
  --units        only install the systemd unit templates (scripts/units),
                 backing up changed ones
  --echo-cancel  only write the PipeWire echo-cancel drop-in the optional wake
                 word needs over speakers (asks first; --yes answers it)
  --dry-run      print the plan, change nothing (also with --cua, --units or
                 --echo-cancel)
  --from-plugin  the Omarchy plugin was added from the marketplace: install
                 the daemon only, leave the plugin directory to `omarchy
                 plugin update`, print every file and the bind line first and
                 ask
  --yes, -y      answer the question yes (--from-plugin, --echo-cancel)
                 (needed without a terminal)
  --ref GIT_REF  install this git ref (branch, tag or commit) of the source
                 repo instead of the working tree
  --repo PATH    source repo for --ref (default: the repo of the last install)

global options:
  --json         machine-readable output (one JSON object)
  --quiet, -q    print nothing on success
  --no-color     plain output (also NO_COLOR, or not a tty)

Examples:
  wispd daemon install
  wispd install --dry-run
  wispd install --units --dry-run
  wispd install --ref origin/master --dry-run
