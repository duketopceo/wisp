usage: wispd recipes approve [-h] [--json] [--quiet] [--no-color] name

Install a drafted recipe as a skill

positional arguments:
  name         recipe-... name from `recipes draft`

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd recipes approve recipe-open-notes
