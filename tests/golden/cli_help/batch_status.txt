usage: wispd batch status [-h] [--json] [--quiet] [--no-color] [job]

List batch jobs from local state (no network)

positional arguments:
  job          job id

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd batch status
  wispd batch status learn-2026-W40
