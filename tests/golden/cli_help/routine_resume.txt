usage: wispd routine resume [-h] [--json] [--quiet] [--no-color] id

Resume a paused routine and install its timer

positional arguments:
  id           the routine id from `wispd routine list`

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd routine resume weekly-digest
