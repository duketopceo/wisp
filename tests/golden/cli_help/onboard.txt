usage: wispd onboard [-h] [--status] [--step ID] [--yes] [--undo ID]
                     [--finish] [--reset] [--tour [STEP]] [--starter]
                     [--interactive] [--json] [--quiet] [--no-color]

Walk through first-run setup (every step skippable)

options:
  -h, --help     show this help message and exit
  --status       print the checklist and exit 0 (the Panel card reads this)
  --step ID      run one step: mic, models, keys, cua, notifications,
                 keybinding
  --yes          with --step notifications: send the test now
  --undo ID      forget one recorded step
  --finish       mark setup finished (hides the Panel card)
  --reset        forget all progress
  --tour [STEP]  the first-minute tour: five spoken steps (hello, draw,
                 circle, ask, dictation); name one step to replay just that
                 one
  --starter      four spoken questions, then three starters to accept or skip
                 (say skip any time to stop)
  --interactive  walk the steps even without a terminal

global options:
  --json         machine-readable output (one JSON object)
  --quiet, -q    print nothing on success
  --no-color     plain output (also NO_COLOR, or not a tty)

Examples:
  wispd onboard
  wispd onboard --status --json
  wispd onboard --step notifications --yes
  wispd onboard --undo mic
  wispd onboard --tour
