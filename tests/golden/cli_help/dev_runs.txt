usage: wispd dev runs [-h] [--json] [--quiet] [--no-color] [RUN_ID]

Run reports: accuracy, outcome mix, drift, cost and time

positional arguments:
  RUN_ID       one run (default: the newest runs)

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd dev runs
  wispd dev runs --json
  wispd dev runs RUN_ID
