usage: wispd eval [-h] [--misses] [--unlabelled] [--by-category]
                  [--gauntlet RUN] [--limit N] [--json] [--quiet] [--no-color]

End-to-end eval: first-time-correct rate per turn kind

options:
  -h, --help      show this help message and exit
  --misses        group the turns that were not right first time
  --unlabelled    list recent turns that still need a label
  --by-category   roll the misses up into failure categories
  --gauntlet RUN  with --by-category: also count the failed attempts of this
                  gauntlet run dir or rows.jsonl (repeatable)
  --limit N       groups or turns to list (default 10)

global options:
  --json          machine-readable output (one JSON object)
  --quiet, -q     print nothing on success
  --no-color      plain output (also NO_COLOR, or not a tty)

Examples:
  wispd eval
  wispd eval --json
  wispd eval --misses
  wispd eval --unlabelled --limit 20
  wispd eval --by-category --gauntlet ~/runs/gauntlet-1
