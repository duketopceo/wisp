usage: wispd task run [-h] [--routine ROUTINE] [--json] [--quiet] [--no-color]
                      [task ...]

Spawn a background agent for a task

positional arguments:
  task               what the agent should do

options:
  -h, --help         show this help message and exit
  --routine ROUTINE  run a scheduled routine by id

global options:
  --json             machine-readable output (one JSON object)
  --quiet, -q        print nothing on success
  --no-color         plain output (also NO_COLOR, or not a tty)

Examples:
  wispd task run fix the flaky login test
  wispd task run --routine inbox-digest
