usage: wispd theme check [-h] [--json] [--quiet] [--no-color] [dir]

Audit the theme's contrast pairs (exit 1 on fail)

positional arguments:
  dir          theme directory (default: the active Omarchy theme)

options:
  -h, --help   show this help message and exit

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd theme check
  wispd theme check ~/.config/omarchy/themes/tokyo-night
