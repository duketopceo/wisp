usage: wispd health start [-h] [--run] [--json] [--quiet] [--no-color]

Print (or with --run, execute) the command that starts down endpoints

options:
  -h, --help   show this help message and exit
  --run        execute the systemctl command (default: print it)

global options:
  --json       machine-readable output (one JSON object)
  --quiet, -q  print nothing on success
  --no-color   plain output (also NO_COLOR, or not a tty)

Examples:
  wispd health start
  wispd health start --run
