Resident voice companion · Omarchy

A small light that shows you the way.

Hold Super+D, speak, and Wisp hears you, decides what you meant, and acts. It keeps the conversation open across utterances, so “check the build”, “open it” and “scroll to the failure” are one task.

v0.9 shipped · Linux (Omarchy/Hyprland)

01 · Voice

It listens when you ask.

Push-to-talk, PipeWire capture, configured speech recognition, then fast-path routing or the act loop.

02 · Pointer

It points at the thing it means.

Replies fly the cursor buddy to the spot on your screen. In the default guide mode Wisp only shows the target, and you click.

03 · Agents

It hands long jobs onward.

Say “Wisp, agent, fix the tests in wisp” and a named task starts on your runtime: opencode, codex, claude or devin. It speaks progress, and asks you out loud when it needs an answer.

04 · Memory

It remembers the thread.

Utterances that share the focused app or the running goal join one goal. Finish a walkthrough, say “save that as a lesson”, and later “replay that lesson” speaks and points at the steps again.

05 · Models

It uses the model you choose.

Hosted models through OpenRouter are the default. Small local models, such as a Liquid AI LFM vision model, are a supported option you turn on yourself. Providers and local tools still need setup. Set [agent] screenshots = "false" to keep images local.

Begin

Install, one step at a time.

●git clone https://github.com/duketopceo/wisp
cd wisp
python3 wispd install   # files, shell plugin, unit, bind
systemctl --user enable --now wispd
wispd onboard           # guided first run
Read the install guide

Every step of onboarding is skippable. macOS and Windows adapters are experimental. The Linux release candidate installer is on the main page.
