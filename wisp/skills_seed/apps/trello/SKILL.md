# trello

## Teaching

### Where things live
- A board is a row of lists, each holding cards. Board menu is at the top right; Filter sits in the board header.
- Open a card to see its description, labels, checklist and dates.

### First steps
- Add a card with the Add a card link at the bottom of a list.
- Add another list with the Add another list box at the end of the row.
- Inside a card, the Dates button sets a due date.

### Pitfalls
- Archiving a card or list hides it from the board; it is not deleted until removed from the archive.
