# gimp

GIMP UI layout and shortcuts:
- **Toolbox (left):** Move (`M`), Rectangle Select (`R`), Crop (`Shift+C`), Bucket Fill (`Shift+B`), Paintbrush (`P`), Text (`T`)
- **Docks (right):** Tool Options (top), Layers/Channels/Paths (bottom, `Ctrl+L`)
- **Export image (PNG/JPG):** `Ctrl+Shift+E` (Save `Ctrl+S` writes `.xcf` only)
- **Scale / canvas size:** `Image -> Scale Image` or `Image -> Canvas Size`
