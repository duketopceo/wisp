# gimp

## Teaching

### Where things live
- Left: the Toolbox. Right: Tool Options above, and the Layers, Channels and Paths tabs below. Center: the image canvas.
- Menus along the top: File, Edit, Select, View, Image, Layer, Colors, Tools, Filters.

### First steps
- Crop: `Shift+C`, drag on the canvas, press `Enter`. Move `M`, Rectangle Select `R`, Text `T`, Paintbrush `P`.
- Resize: Image > Scale Image, or Image > Canvas Size to change the canvas.
- Export a PNG or JPG with File > Export As (`Ctrl+Shift+E`). `Ctrl+S` saves a .xcf project only.
