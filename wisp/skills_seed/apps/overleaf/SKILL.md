# overleaf

## Teaching

### Where things live
- Left: the file tree and outline. Center: the source editor. Right: the PDF preview. Top: the menu button, Share and History.
- The Recompile button sits above the preview.

### First steps
- Recompile above the PDF compiles; `Ctrl+Enter` does the same.
- Share at the top right adds collaborators by email or makes a link.
- The upload icon in the file tree adds files.
- Menu at the top left holds the compiler and main document settings.

### Pitfalls
- A compile error list appears under the Recompile button; start with the first error.
