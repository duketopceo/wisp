# firefox

Firefox shortcuts and UI landmarks:
- **Address bar:** `Ctrl+L` or `Alt+D`
- **Tabs:** `Ctrl+T` new, `Ctrl+W` close, `Ctrl+Shift+T` undo close, `Ctrl+PageDown/PageUp` switch
- **Settings & add-ons:** `about:preferences`, `Ctrl+Shift+A` for extensions
- **Developer tools:** `Ctrl+Shift+I`; **Reader view:** `F9`
- **Application menu:** hamburger icon at top-right of toolbar
