# gnome-text-editor

## Teaching

### Where things live
- Top: the header bar with Open, the document tabs and a menu button. The menu holds Preferences and Keyboard Shortcuts.
- Font, colour scheme and line numbers are under Preferences.

### First steps
- `Ctrl+N` new document, `Ctrl+O` open, `Ctrl+S` save, `Ctrl+Shift+S` save as, `Ctrl+W` close the tab.
- `Ctrl+F` finds text and `Ctrl+H` opens find and replace. `Ctrl+I` goes to a line number.
- `Ctrl+Comma` opens Preferences in Text Editor.

### Linux pitfalls
- Text Editor keeps unsaved drafts and restores them; still tell the user to save before closing when the file matters.
