# joplin

## Teaching

### Where things live
- Left: notebooks and tags. Middle: the note list. Right: the editor (Markdown on one side, preview on the other). Top: new note, new to-do and new notebook buttons.
- Tools, Options holds settings and sync.

### First steps
- `Ctrl+N` creates a note and `Ctrl+Shift+N` creates a notebook.
- `Ctrl+Shift+T` adds tags to the current note.
- Tools, Options, Synchronisation picks the target and credentials.
- `Ctrl+Shift+F` focuses the search box.

### Pitfalls
- Layout toggles between editor and viewer panes are under the View menu.
