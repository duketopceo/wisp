# kitty

Terminal emulator (kitty / alacritty / ghostty) shortcuts:
- **Copy / Paste:** `Ctrl+Shift+C` / `Ctrl+Shift+V` (never bare `Ctrl+C`, which sends SIGINT)
- **Tabs & Windows:** `Ctrl+Shift+T` new tab, `Ctrl+Shift+Q` close tab, `Ctrl+Shift+Enter` new split
- **Font size:** `Ctrl+Shift+Equal` zoom in, `Ctrl+Shift+Minus` zoom out
- **Scrollback search:** `Ctrl+Shift+H` in kitty
