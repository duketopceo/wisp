# gitlab

## Teaching

### Where things live
- Left sidebar: project areas such as Code, Plan, Build and Deploy. Top: the search box.
- The merge request page has Overview, Commits, Pipelines and Changes tabs.

### First steps
- Review a merge request: open it, go to the Changes tab, read the diff, then use the Review button.
- Failed pipeline: Build, Pipelines in the sidebar, open the pipeline and click the red job for its log.
- New issue: Plan, Issues, then New issue.
- Press `?` on a page to list the keyboard shortcuts.

### Pitfalls
- Menu names in the sidebar differ between GitLab versions, so name the area and let the learner find the exact entry.
