# kate

## Teaching

### Where things live
- Top: the menu bar. Left: the sidebar tabs (Documents, Projects, Filesystem). Bottom: tool views such as Terminal and Output.
- Settings, Configure Kate holds editor and shortcut options.

### First steps
- `Ctrl+O` opens a file; `Ctrl+S` saves; `Ctrl+Shift+S` saves as.
- `Ctrl+Alt+I` opens the command bar to search for any action.
- The View menu has the split vertical and horizontal commands.
- `F4` toggles the embedded terminal.

### Pitfalls
- Sessions are under the Sessions menu; one session remembers which files and layout were open.
