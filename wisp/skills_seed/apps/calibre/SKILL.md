# calibre

## Teaching

### Where things live
- Top: a toolbar with Add books, Edit metadata, Convert books and View. Centre: the book list. Right: the details panel for the selected book.
- A search bar sits above the list.

### First steps
- `A` adds books, `E` edits metadata, `C` converts, `V` views the selected book.
- `Ctrl+P` opens Preferences.

### Linux pitfalls
- calibre copies a book into its own library folder; the original file is not moved or removed.
