# thunar

## Teaching

### Where things live
- Top: a menu bar (File, Edit, View, Go, Bookmarks, Help), then the location bar. Left: the side pane with places and devices.
- Opening a terminal in the current folder is under the File menu.

### First steps
- `Ctrl+L` types a path. `Ctrl+H` shows or hides hidden files. `Ctrl+Shift+N` new folder.
- `Ctrl+T` new tab, `Ctrl+N` new window, `F2` renames the selected file.
- The View menu switches icon, list and compact layouts and toggles the side pane.

### Linux pitfalls
- `Delete` moves to the Trash; `Shift+Delete` deletes for good. Never suggest it as the default.
