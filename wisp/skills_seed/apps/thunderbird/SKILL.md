# thunderbird

Thunderbird email client shortcuts:
- **New message:** `Ctrl+N`; **Send message:** `Ctrl+Enter`
- **Reply / Reply All / Forward:** `Ctrl+R` / `Ctrl+Shift+R` / `Ctrl+L`
- **Search messages:** `Ctrl+K` (global search) or `Ctrl+Shift+K` (quick filter bar)
- **Archive / Delete:** `A` (archive), `Delete` (move to trash)
