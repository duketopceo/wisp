# signal

## Teaching

### Where things live
- Left: the conversation list with a search box at the top. Center: the open chat with the message box at the bottom.
- The menu under your avatar at the top left holds Settings.

### First steps
- The plus button beside the message box attaches files.
- Open a chat's menu, then Disappearing messages, and pick a time.
- Linking is done from the phone's Linked devices screen, scanning the code shown on first run.
- Never read out safety numbers or message contents; describe where they live.

### Pitfalls
- Messages are private; teach controls and locations only, without reading conversation text aloud.
