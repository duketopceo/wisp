# vscode

VS Code / Cursor shortcuts and layout:
- **Command Palette:** `Ctrl+Shift+P` (or `F1`); **Quick Open file:** `Ctrl+P`
- **Toggle sidebar / terminal:** `Ctrl+B` (sidebar), `Ctrl+\`` (integrated terminal)
- **Activity Bar (left):** Explorer (`Ctrl+Shift+E`), Search (`Ctrl+Shift+F`), Source Control (`Ctrl+Shift+G`), Extensions (`Ctrl+Shift+X`)
- **Settings:** `Ctrl+,`
