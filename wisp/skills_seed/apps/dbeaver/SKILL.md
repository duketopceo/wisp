# dbeaver

## Teaching

### Where things live
- Left: the Database Navigator listing connections and tables. Center: editors. Top: the toolbar with the SQL Editor button.
- Connections are made with the plug icon at the top left.

### First steps
- Select a connection, then use SQL Editor, Open SQL script from the menu or the toolbar button.
- `Ctrl+Enter` runs the statement under the cursor; `Alt+X` runs the whole script.
- Double click a table to open its data; the Data tab shows rows.
- The Export data button under the result grid starts the export wizard.

### Pitfalls
- A new connection may prompt to download a database driver the first time; that is expected.
