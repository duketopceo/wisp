# libreoffice

## Teaching

### Where things live
- Top to bottom: menu bar (File, Edit, View, Insert, Format...), toolbars, the document, then the status bar. The right sidebar holds Properties, Styles and Navigator.
- Calc adds a formula bar with a Name Box above the grid.

### First steps
- `Ctrl+S` saves in the document format. PDF: File > Export As > Export as PDF.
- `Ctrl+H` Find and Replace. `F11` Styles, `F5` Navigator (Writer), `Ctrl+Alt+C` insert a comment.
- Calc: start a formula with `=`, `F2` edits the active cell, `Ctrl+;` inserts today's date.

### Linux pitfalls
- File > Save may ask to keep the format when the file is .docx or .xlsx; the Keep Current Format button keeps it.
