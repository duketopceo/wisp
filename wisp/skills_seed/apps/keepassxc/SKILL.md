# keepassxc

## Teaching

### Where things live
- Menu bar on top: Database, Entries, Groups, Tools, View, Help. The toolbar has icons for new entry, copy username and copy password. Groups are on the left and entries on the right; the search box is at the top right.

### First steps
- Entries, then New Entry, or the plus icon in the toolbar.
- `Ctrl+F` jumps to the search box.
- `Ctrl+L` locks all databases.

### Pitfalls
- Never read usernames, passwords, notes or codes aloud; point at the control and let the user look.
