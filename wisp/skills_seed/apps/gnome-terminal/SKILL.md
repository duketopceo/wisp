# gnome-terminal

## Teaching

### Where things live
- Top: the tab bar, with a plus button for a new tab. Top right: the menu button, which holds Preferences and Keyboard Shortcuts.
- Profiles (colours, font, scrollback) are under Preferences, one profile per row on the left.

### First steps
- Copy is `Ctrl+Shift+C`, paste is `Ctrl+Shift+V`. Bare `Ctrl+C` stops the running program.
- `Ctrl+Shift+T` new tab, `Ctrl+Shift+N` new window, `Ctrl+Shift+W` close tab.
- `Ctrl+PageUp` and `Ctrl+PageDown` switch tabs; `Alt+1` to `Alt+9` jump to a tab.
- `Ctrl+Shift+F` finds text in the output. `Ctrl+Plus`, `Ctrl+Minus` and `Ctrl+0` change the text size.

### Linux pitfalls
- Selecting text fills the primary selection; middle-click pastes it, separate from the clipboard.
