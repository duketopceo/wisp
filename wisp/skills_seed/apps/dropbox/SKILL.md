# dropbox

## Teaching

### Where things live
- Left: Home, All files, Shared and Deleted files. Top: the search box. The right side holds Upload and Create buttons.
- Hovering a file shows Share and more options.

### First steps
- Upload, then Files or Folder.
- Hover a file and click Share, then Create link or invite by email.
- Deleted files lists removed items with a Restore button.
- The file's Version history option lists older versions.

### Pitfalls
- Link access settings (anyone or only invited) matter; point to the share dialog's access option.
