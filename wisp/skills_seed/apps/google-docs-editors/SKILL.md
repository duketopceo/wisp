# google-docs-editors

## Teaching

### Where things live
- Top: the menu bar (File, Edit, View, Insert, Format and more) and the toolbar. Top right: the Share button and Comments. Slides adds a Slideshow button; Sheets has the formula bar above the grid.
- The title is at the top left; click it to rename.

### First steps
- Share opens a dialog to add people or change link access.
- Select text, then use the add comment button in the margin or the Insert menu.
- File, Version history, See version history lists earlier edits.
- `Ctrl+/` opens the list of keyboard shortcuts.

### Pitfalls
- Docs, Sheets and Slides share this host; check the page's path (document, spreadsheets, presentation) to know which app is open.
