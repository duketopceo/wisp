# stack-overflow

## Teaching

### Where things live
- Top: the search box and site navigation. Left: Home, Questions, Tags. Each question page lists answers below the question, with the accepted one marked by a green check.
- Sorting for answers sits above them.

### First steps
- Search from the top box; add tags in square brackets, for example `[python]`, to narrow results.
- Ask a question: the Ask Question button on the Questions page; write a title, the details, and add tags.
- The accepted answer has a green check; the highest voted can differ from it.
- Vote with the arrows next to a post when signed in.

### Pitfalls
- Read the dates; an old accepted answer may be out of date for current tool versions.
