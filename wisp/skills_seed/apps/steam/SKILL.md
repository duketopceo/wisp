# steam

Steam desktop client landmarks:
- **Top navigation bar:** Store, Library, Community, Profile
- **Downloads manager:** bottom bar center (`Downloads` status link)
- **Settings:** `Steam` menu (top-left) -> `Settings`
- **Add / Activate game:** bottom-left `+ Add a Game` button
