# hyprland

Omarchy/Hyprland window and workspace bindings:
- **Close window:** `Super+W`
- **Toggle floating / fullscreen:** `Super+V` (float), `Super+F` (fullscreen)
- **Switch workspace:** `Super+1..9`, move window with `Super+Shift+1..9`
- **Focus direction:** `Super+Arrow` or `Super+H/J/K/L`
- **Reload config:** `hyprctl reload && hyprctl configerrors`
