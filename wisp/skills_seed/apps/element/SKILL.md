# element

## Teaching

### Where things live
- Left: spaces strip and the room list. Center: the timeline and composer. Top left: your avatar menu with All settings.
- Room info opens from the header.

### First steps
- The plus button above the room list starts a chat or explores public rooms.
- Avatar menu, All settings, Security and Privacy, then the session list to verify a device.
- `Ctrl+K` opens the room search.
- Hover a message and use the thread icon to reply in a thread.

### Pitfalls
- Encrypted rooms need device verification before history decrypts on a new device; point to the security settings.
