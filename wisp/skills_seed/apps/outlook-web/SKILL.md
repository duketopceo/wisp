# outlook-web

## Teaching

### Where things live
- Left: the app rail (Mail, Calendar, People) and the folder list. Top: the search box and the gear for settings. Above the list: New mail.
- The reading pane sits on the right.

### First steps
- New mail opens the compose pane.
- The top search box searches all folders; narrow it with the dropdown.
- Settings, Mail, Rules creates a rule.
- Right click a message for move, categorise and flag options.

### Pitfalls
- Never read message bodies aloud; describe where controls are.
