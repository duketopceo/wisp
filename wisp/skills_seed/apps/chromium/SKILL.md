# chromium

## Teaching

### Where things live
- Top row: tab strip, then the toolbar with back, forward, reload, the address bar, and the three-dot menu at the far right.
- Settings, history and downloads open as tabs; the three-dot menu lists them.

### First steps
- `Ctrl+L` focuses the address bar. `Ctrl+T` new tab, `Ctrl+W` close, `Ctrl+Shift+T` reopen the last closed tab.
- `F12` or `Ctrl+Shift+I` opens DevTools. `Ctrl+F` finds in the page. `Ctrl+J` downloads, `Ctrl+H` history.

### Linux pitfalls
- A web app opened by Omarchy runs in an app window with no tab strip or address bar; the shortcuts above still work, the toolbar is absent.
