# chromium

Chromium / Chrome shortcuts and UI landmarks:
- **Address bar (omnibox):** `Ctrl+L` to focus URL/search
- **Tabs:** `Ctrl+T` new, `Ctrl+W` close, `Ctrl+Shift+T` reopen, `Ctrl+Tab` cycle
- **Find in page:** `Ctrl+F`; **DevTools:** `Ctrl+Shift+I` or `F12`
- **Settings / downloads / history:** `Ctrl+,` / `Ctrl+J` / `Ctrl+H`
- **Menu button:** three vertical dots at top-right of toolbar
