# asana

## Teaching

### Where things live
- Left sidebar: Home, My tasks, Inbox, then Projects. A project has tabs along the top: Overview, List, Board, Timeline, Calendar.
- The Add task button sits at the top of a project.

### First steps
- Click Add task, type a name, then Enter.
- Open a task and use the Assignee field to assign it.
- Choose the Board tab in a project to see columns.

### Pitfalls
- Tasks can be in several projects at once; removing from one project does not delete the task.
