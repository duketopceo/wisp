# virt-manager

## Teaching

### Where things live
- The main window lists machines with their state. The toolbar above has New, Open, Run, Pause and Shut Down buttons.
- Edit, Connection Details shows storage and networks.

### First steps
- The first toolbar button, or File, New Virtual Machine, starts the creation wizard.
- Select a machine and press Run in the toolbar; Open shows its console.
- In the machine's Details view, pick the CD-ROM device and browse to an ISO.
- In a console, the release-pointer key combination is shown in the window title bar.

### Pitfalls
- Machines use the system or session connection; one will not list the machines of the other.
