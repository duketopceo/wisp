# kdenlive

## Teaching

### Where things live
- Top left: the Project Bin with imported clips. Top centre: the clip and project monitors. Bottom: the timeline with its tracks.
- Render is under the Project menu, and Effects and Transitions are tabs next to the bin.

### First steps
- `Ctrl+I` adds a clip to the bin; drag it from the bin onto a track.
- `Space` plays and pauses. `Delete` removes the selected clip. `Ctrl+Z` undoes.
- `Ctrl+Enter` opens the Render dialog; pick a preset and a file name, then render.

### Linux pitfalls
- `Ctrl+S` saves the project file only; the finished video does not exist until Render runs.
