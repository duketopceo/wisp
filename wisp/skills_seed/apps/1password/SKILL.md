# 1password

1Password shortcuts (desktop app and browser vault):
- **Quick Access (global):** `Ctrl+Shift+Space` opens the search overlay
- **Lock vault:** `Ctrl+Shift+L`
- **Autofill in browser:** `Ctrl+\` with the browser extension
- **Never read, speak, or type a secret aloud** — hand off to the user for
  copy/paste of passwords, TOTP codes, and recovery keys.
