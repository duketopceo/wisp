# nvim

Neovim (LazyVim / Omarchy default) keybinds:
- **Leader key:** `Space` in Normal mode
- **Find files / grep:** `Space Space` (files), `Space /` (live grep), `Space fb` (buffers)
- **File explorer (neo-tree):** `Space e`
- **Save / quit:** `:w` (`Ctrl+S`), `:q`, `:wq`
- **LSP actions:** `gd` goto definition, `gr` references, `Space ca` code action
