# whatsapp-web

## Teaching

### Where things live
- Left: the chat list with a search box. Center: the conversation with the message box at the bottom. The icon strip at the top of the list holds new chat and the menu.
- Settings are in the menu or the bottom left icon.

### First steps
- The search box filters chats; the magnifier in a chat header searches that chat.
- The plus or paperclip beside the message box attaches a file.
- Linking: the phone's Linked devices screen scans the QR code on the sign in page.
- `Ctrl+N` starts a new chat.

### Pitfalls
- Messages are private; teach controls and locations only, without reading conversation text aloud.
