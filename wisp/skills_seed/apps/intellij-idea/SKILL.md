# intellij-idea

## Teaching

### Where things live
- Left edge: tool window buttons (Project, Structure, Git). Bottom edge: Run, Debug, Terminal. Top right: the run configuration selector and the search icon.
- Settings are under File, Settings.

### First steps
- Press `Shift` twice to open Search Everywhere; `Ctrl+Shift+A` finds an action by name.
- `Shift+F10` runs the current configuration; `Shift+F9` debugs it.
- `Shift+F6` renames the symbol under the caret across the project.
- `Alt+Enter` shows quick fixes; `Ctrl+Alt+L` reformats the code.

### Pitfalls
- Community and Ultimate editions share the window class; some menus exist only in Ultimate.
