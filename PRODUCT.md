# Wisp

<!-- impeccable:product-schema 1 -->

## Platform

web

This record describes the website. The product itself is a Python daemon
and Quickshell companion for Omarchy/Hyprland.

## Users

Omarchy users who want to speak a task without leaving the desktop they
are looking at. Linux is the full-app priority; macOS and Windows are
experimental probe work, not supported full desktop releases.

## Product Purpose

Speak to a companion that can explain, point, and act on the computer.
The owner prioritizes fast, accurate execution and understandable feedback.

## Operating Context

Push-to-talk, browser profiles for personal and work, spoken answers,
sensitive-surface confirmation, app skills, and local run diagnostics.

## Capabilities and Constraints

The repository implements cloud, local, and safe configuration presets.
Code and deterministic tests do not prove real-desktop task success.
Real model latency and accuracy must come from labeled runs, not examples.
The website must never access a visitor's microphone, accounts, or desktop.

## Brand Commitments

Wisp. The owner selected `wisp.observer` and requested an interactive
Three.js landing page, with Impeccable refinement. Preserve the ember
companion and restrained desktop chrome visible in the repository assets.
The owner authorized continuing the existing design and roadmap through LFG.

## Evidence on Hand

`README.md`, `ROADMAP.md`, `docs/TRUST.md`, `site/costs.json`,
`shell-plugin/lib/creature.js`, and `assets/readme/companion.png`.
No current measured speed claim or completed production-domain deployment
is established by this record. A website simulation is not an app recording.

## Product Principles

- Show the state of a task rather than narrating imaginary success.
- Read and navigate sensitive surfaces; confirm mutations.
- Keep setup and configuration simple.
- Measure first, compare providers using actual run data.
