# draw-and-teach
title: Draw on the screen, hear it explained
length: 45
setup: Open the app you want to learn (the demo uses a real one, a file manager or an editor) and a clean workspace. No password manager or banking window visible.
proof: result=ANSWERED && transcript~what does this
## steps
- show Hold the talk key, draw a ring round the thing you do not understand, ask.
- human 2 Put the pointer over the app, nothing else on screen
- say 9 "What does this button do?"
- wait 12
